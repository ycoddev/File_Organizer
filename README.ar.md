# File Organizer 🗂️

سكربت بايثون بسيط بينظم الملفات في فولدر معين تلقائياً حسب نوعها - بينقل الصور وملفات الـPDF والفيديوهات كل واحدة لفولدرها.

## المميزات
- بيكتشف نوع الملف تلقائياً حسب الامتداد
- بيعمل الفولدرات المطلوبة لو مش موجودة
- بينقل كل ملف لفولدره المناسب
- بينبه على الملفات اللي نوعها مش معروف بدل ما يتوقف بخطأ

## التقنيات المستخدمة
- Python 3
- مكتبة `os` (للتعامل مع الملفات والفولدرات)

## طريقة الاستخدام
1. حط السكربت في نفس المكان اللي فيه الفولدر اللي عايز تنظمه
2. غيّر قيمة `folder_path` لاسم الفولدر بتاعك
3. شغّل السكربت:
```bash
python main.py
```
